ALEX DANTAS MOTOBOY - PWA
1. Edite config.js com SUPABASE_URL e SUPABASE_ANON_KEY.
2. Execute supabase-motoboy.sql no Supabase depois da tabela delivery_requests.
3. Publique como Static Site no Render usando HTTPS.
4. No celular, toque ATIVAR SOM uma vez; depois novos pedidos geram alerta sonoro. Navegadores bloqueiam autoplay antes da interação.
5. O viewport bloqueia zoom por gesto e o layout se adapta a telas pequenas.
